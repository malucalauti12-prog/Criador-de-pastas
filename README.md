# 📁 Criador de Pastas

Aplicativo desenvolvido em Python para automatizar a criação e organização de pastas no Windows.

## 📌 O que o programa faz

O **Criador de Pastas** permite criar pastas de forma rápida e organizada, automatizando uma tarefa que normalmente seria feita manualmente pelo Explorador de Arquivos do Windows.

O objetivo do projeto é facilitar tarefas repetitivas e aplicar conceitos de **programação e automação** na prática.

## 🛠️ Tecnologias

* 🐍 Python
* 📦 PyInstaller
* 🪟 Windows

## 💻 Como usar

1. Baixe o arquivo `.exe` na seção de download.
2. Abra o aplicativo.
3. Escolha as opções disponíveis no programa.
4. Execute a criação das pastas.
5. As pastas serão criadas automaticamente no local escolhido.

> Não é necessário ter o Python instalado para utilizar o arquivo `.exe`.
